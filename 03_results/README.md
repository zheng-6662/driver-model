# 03_results

这个目录只放运行输出、分析产物和备份，不放当前维护代码。

当前分区说明：

- `tmp/`：临时运行目录、协议安全实验输出、短期核验结果。
- `output/`：文档、PDF、PPT、Visio 等导出件。
- `artifacts/`：分析产物、整理包和归档结果。
- `多模态数据/程序运行结果/`：从旧工作区拆出的历史运行结果。
- `backups/`：备份件。
- `cache/`、`metadata/`、`zotero_records/`：缓存、元数据和文献相关产物。

使用约定：

- 训练与评估默认输出应该落到这里，而不是散落在代码目录。
- 当前主线模型默认结果根目录是 `多模态数据/程序运行结果/`。
- 历史运行副本可以继续保留，但不要把其中的脚本当成活动源文件直接修改。
