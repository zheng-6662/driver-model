# 02_code

这个目录放当前维护代码、工具和历史脚本，不放实验输出。

当前分区说明：

- `final_code/`：当前维护主线。平时优先在这里修改。
- `tools/`：分析、导出、重算、可视化等辅助工具。
- `startup/`：项目启动、看板、桥接和环境辅助脚本。
- `legacy_multimodal/`：从旧多模态工作区拆出的历史代码，只保留作参考。
- `scripts/`：独立脚本或一次性整理后保留的脚本入口。
- `workspace/`：外部工作区或辅助代码工作区。

使用约定：

- 需要继续维护的代码，优先收口到 `final_code/`。
- `legacy_multimodal/` 里的脚本不要直接当活动主线运行；若要继续用，先迁入 `final_code/` 或 `tools/` 再修路径。
- 与新目录布局相关的默认路径，应从仓库根目录推导到 `01_datasets/`、`03_results/`、`04_project_logs/`。
