# 事件样本 v0.6 筛选规则草案

生成时间：2026-05-12

依据：GPTPro 对 v0.4/v0.5 事件锚点重建和候选筛选的审查意见。

## 总原则

v0.6 的目标不是扩大样本数量，而是先形成一批因果语义清楚、锚点不混、方向符号可信、响应窗口完整的样本。第一版模型宁可小而干净，不要大而混杂。

本阶段仍不训练模型。v0.6 先解决“哪些事件能作为第一版训练样本”。

## 事件时间层级

后续每个事件尽量保留多层时间，而不是只有一个 `anchor_time`：

| 字段 | 含义 | 是否作为训练锚点 |
|---|---|---|
| `t_design` | 场景/道路设计点，例如道路入口、曲率开始、低附着区域设计点 | 候选 |
| `t_trigger` | `.aed` 显式触发点，例如 ChangeLane / Stop | 候选 |
| `t_ego_exposure` | 事件真正影响被试的时刻，例如目标车侵入路径、TTC 下降、被试进入低 μ | 优先候选，但当前不一定全自动可得 |
| `t_response_onset` | 车辆响应开始时刻 | 只作确认，不直接定义因果锚点 |
| `t_response_peak` | 车身或方向盘响应峰值 | 只作确认/评估，不定义因果锚点 |
| `t_train_anchor` | 最终用于切片训练的锚点 | v0.6 输出 |

## v0.6 四类输出表

1. `primary_training_events_v0_6.csv`  
   可进入第一版训练的强样本。

2. `manual_review_events_v0_6.csv`  
   需要人工确认或后续补证据的样本。

3. `response_confirm_only_v0_6.csv`  
   只能作为响应确认点，不能作为事件锚点的样本。

4. `holdout_or_excluded_v0_6.csv`  
   暂缓、排除或语义不清样本。

## 样本分级

### S 级：第一版训练核心样本

必须满足：

- 有外生设计证据：`.aed`、raw `mu`、道路几何或已验证 cfg；
- 被试相关性明确；
- `t_train_anchor` 前没有明显同一事件响应已经开始；
- `t_train_anchor` 后在合理窗口内有车辆响应；
- 方向盘标签连续，符号可信；
- 历史和未来窗口完整；
- 横向偏移/道路坐标没有明显非物理跳变；
- 左/右方向或曲率方向可解释。

### A 级：可训练但保留复核标记

允许存在轻微问题，例如响应稍晚、旧锚点不一致、车辆响应中等、被试相关性需要后续补证据。

### B 级：弱响应/负样本/对照样本

显式触发发生，但被试没有明显方向盘响应。这类样本不直接混入强响应回归，可作为：

- 是否产生明显转向响应的分类任务；
- no-response/control 样本；
- 防止模型过度预测的对照。

### C 级：响应确认-only

包括横向加速度峰值、横摆角速度峰值、横滚速率峰值、横向偏移变化峰值、方向盘速率峰值等。它们只能说明响应发生，不能作为因果锚点。

### D 级：排除或暂缓

包括：

- 只有旧锚点，没有设计证据；
- 只有方向盘峰值，没有外生事件；
- `t_train_anchor` 前响应已经明显开始；
- 样本窗口不完整；
- 坐标跳变无法解释；
- 场景语义不清；
- `curve3/zd` 当前覆盖和语义不足；
- `stop` 缺少前车触发、相对距离或 TTC 证据。

## 分场景处理规则

| 场景 | v0.6 处理 | 原因 |
|---|---|---|
| `curve1/curve2` | 第一批核心候选，但锚点应从模块入口细化为曲率开始/有效曲率点 | 道路几何语义稳定 |
| `differentmu_road` | 第一批核心候选，优先 raw `mu` 跳变/首次低附着 | 物理依据强，直接来自被试车 |
| `fix_road` 显式变道 | 第一批或 1.5 批候选，必须看图确认 timing | 有显式变道触发且高置信候选较多 |
| `middle_section` | 暂不进入第一版单点事件训练；单独作为连续任务/episode | 连续超车不是单点突发事件 |
| `longstraight` 显式变道 | 暂缓为诊断/小样本复核集 | 高置信少，需要确认被试相关性和暴露点 |
| `longstraight` 显式停车 | 单独作为纵向/避让事件，不先进 steering 主训练 | 停车主要驱动制动/减速 |
| `stop` | 暂缓 | 当前高置信为 0，缺少前车/TTC 证据 |
| `curve3/zd` | 暂缓 | 当前记录级候选不足或语义不清 |

## 第一版核心训练样本建议

第一版 `primary_training_events_v0_6` 只考虑：

1. `curve1/curve2`：通过复核的几何锚点；
2. `differentmu_road`：raw `mu` 跳变或首次低附着；
3. `fix_road`：人工复核通过的显式变道样本。

暂不混入：

- `middle_section`；
- `longstraight` 大部分样本；
- `longstraight stop`；
- `stop`；
- `curve3`；
- `zd`。

## 当前不能做的事

1. 不能把 v0.5 高置信 314 个候选直接训练。
2. 不能把方向盘峰值或车身姿态峰值作为主因果锚点。
3. 不能把 `middle_section` 和突发事件混成一个单点事件池。
4. 不能在 v0.6 样本清单未固定前继续验证连续风格或生理数据有效性。
