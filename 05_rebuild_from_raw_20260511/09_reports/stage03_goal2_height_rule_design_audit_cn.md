# Goal2 高度异常规则设计文件核查

日期：2026-05-26

## 为什么做

用户指出：当前 `03_C2_高度姿态明显_谨慎复核` 中很多样本的高度变化只有十几厘米到二十厘米左右，这种变化不像真实“下马路、上斜坡、驶出道路”。因此需要回到道路设计文件，确认实验道路本身的高程变化尺度，再修正“高度异常”的判断规则。

## 对现有 Goal2 排除结果的复查

Goal2 中被严格排除的 `excluded_slope_or_offroad` 样本共有 1407 个。按当前 `v2_0_height_pose_issue` 字段统计：

| 高度/姿态标记 | 数量 |
|---|---:|
| 高度微动正常 | 941 |
| 明显高度异常 | 270 |
| 轻度高度/姿态复核 | 80 |
| 高度小幅复核 | 60 |
| 高度轻微变化 | 56 |

其中大量被排除样本其实是“高度微动正常”，说明 Goal2 严格排除过多依赖旧版本文字和旧版本标签，不适合作为最终硬规则。

对恢复优先级 A/B 档样本统计：

- A/B 可恢复候选共 1057 个。
- 这些样本的 `z_residual_range_v1_3` 中位数约为 0.0055 m。
- 75% 分位约为 0.0099 m。
- 95% 分位约为 0.0697 m。
- 99% 分位约为 0.0970 m。
- 全部 A/B 样本的 `z_residual_range_v1_3` 都小于等于 0.1 m。

这进一步说明：很多被 Goal2 排除的样本只有厘米级高度残差，不应作为“下马路/上斜坡/驶出道路”的硬排除证据。

## 修正规则

后续高度异常规则应改为：

1. 不再把 `v2_0_height_pose_issue == 明显高度异常` 直接作为硬排除条件。
2. 不再把旧版本文字中的“高度异常、上斜坡、下马路、roadedge、offroad”等结论直接继承为硬排除。
3. `z_residual_range < 0.20 m`：默认视为车辆姿态、悬架、采样或道路参考误差范围内的小幅高度变化，不能作为排除依据。
4. `0.20 m <= z_residual_range < 0.50 m`：只能进入复核，不硬排除。
5. `z_residual_range >= 0.50 m`：仍需结合道路坐标、道路模块、车辆轨迹、横向偏移参考系、速度、制动、横摆、横滚和方向盘变化判断；不能单靠高度排除。
6. `z_residual_range >= 1.00 m` 或出现明显不符合道路设计的持续高度偏离时，才作为强排除候选。
7. 对 `curve1/curve2`，不能用原始 `z_range` 判异常，因为正常道路设计本身有 6 到 7 m 的下坡高程变化；必须比较“车辆 z 相对道路设计 z 的残差”。
8. 对非弯道路段，十几厘米以内的高度变化更可能是车身姿态/悬架/车辆动态或坐标参考问题，不应直接判定为上下马路。

## 下一步影响

- Goal2 严格排除结果需要降级，不能作为最终训练集排除标准。
- 下一版样本恢复应同时修正两类误判：
  1. 横向偏移跳变：降级为道路/车道参考系切换提示；
  2. 小幅高度变化：降级为高度微动/姿态提示。
- 建议下一版规则命名为“道路设计高程校正后的样本恢复规则”，输出新的恢复候选表和训练候选表后，再重跑 vehicle-only 对照。
