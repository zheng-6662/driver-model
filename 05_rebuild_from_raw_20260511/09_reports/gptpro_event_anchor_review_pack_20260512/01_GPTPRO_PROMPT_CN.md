# 可复制给 GPTPro 的问题

我们现在正在做事件触发后的方向盘转角轨迹预测模型。之前模型无论怎么改，整体效果提升都不明显，预测图里经常出现“趋势像，但物理意义不对”的问题：比如真实是明显大幅打方向，模型预测成轻微变化；或者真实和预测在零线两侧，方向意义完全不同。因此我们开始怀疑，问题不一定只在模型结构，也可能在事件锚点和样本构建上。

当前目标不是继续训练模型，而是重新审查旧流程里的事件锚点是否合理，尤其是：事件发生时刻、被试实际感知到事件的时刻、车辆开始响应的时刻、方向盘响应峰值，这几者不能混为一谈。

请你结合这个压缩包中的报告、表格和代表性复核图，重点审查以下问题：

1. 我们现在从“继续改模型”转向“重审事件锚点和样本构建”，这个判断是否合理？
2. 当前把事件拆成“场景设计点、显式触发点、车辆响应确认点、方向盘预测标签”这四层，逻辑是否正确？
3. v0.4 候选锚点重建是否有明显逻辑漏洞？例如是否漏掉了某类场景，或者把某些不该比较的点混在一起？
4. v0.5 自动筛选的思路是否合理？即用“设计证据 + 车身响应 + 窗口完整性 + 旧锚点接近程度”来筛候选。
5. 当前 `middle_section` 高置信候选很多，但它是连续超车负荷，不是单点突发事件。后续应该如何处理这类连续任务？是用段入口、响应开始点，还是拆成多个子事件？
6. `longstraight` 显式变道高置信较少，而显式停车更多进入高置信复核。这应该如何解释？是变道触发没有影响被试，还是我们的响应判断指标/窗口不适合？
7. `fix_road` 显式变道有一批高置信候选，是否说明维修/施工变道比直道变道更适合进入新样本？
8. `curve1/curve2` 和 `differentmu_road` 看起来更稳定，因为它们有道路几何或路面附着依据。是否应该先用这些场景建立第一版可靠样本集？
9. 旧流程中用方向盘速率峰值或车辆响应反推锚点，这是否可能导致标签泄漏或事件语义偏晚？
10. 下一步 v0.6 样本清单应该怎么定规则？请给出明确的纳入、排除、人工复核和降级标准。

请按以下格式回答：

第一部分：判断当前事件锚点重建方向是否正确；

第二部分：指出当前 v0.4/v0.5 中最可能存在的逻辑漏洞；

第三部分：建议 v0.6 样本清单如何筛选；

第四部分：建议哪些场景先进入模型训练，哪些暂缓；

第五部分：建议如何处理连续超车、显式变道、低附着、弯道、停车这些不同事件类型；

第六部分：判断是否应该先用新锚点训练一个车辆-only 强基线，再谈连续驾驶风格和生理数据；

第七部分：给出后续最小但可靠的执行路线。

最终目标仍然是：建立一个更可靠的方向盘转角轨迹预测模型，并最终证明连续驾驶风格和生理数据是否能在强车辆基线之上提供真实增量。但在事件锚点和样本清单没有确认前，我们不希望继续盲目训练模型。
