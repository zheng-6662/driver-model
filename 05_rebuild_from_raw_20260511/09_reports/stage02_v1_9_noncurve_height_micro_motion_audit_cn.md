# v1.9 非弯道高度微小变化审计

## 审计问题

用户提出：直路或非弯道事件发生时，高度 z 是否也会有零点零几米的轻微变化，可能来自车辆侧倾、姿态变化、悬架或车身动态，而不是开上/下路边。

本审计只回答一个问题：**非弯道事件中的高度小波动是否普遍存在，以及它能否作为事件筛选依据。**

## 使用数据

- 输入总表：`F:\data_set_process\data_process\05_rebuild_from_raw_20260511\02_samples\record_level_episode_reconstruction_v1_9_coord_curve_revised\tables\record_level_episodes_all_v1_9.csv`
- 道路判断：沿用 v1.9 的道路坐标匹配结果，只有 `curve1/curve2/curve3` 才算弯道。
- 高度指标：优先看 `z_residual_range_v1_3`，即去掉整体坡度/趋势后的高度残差范围；`z_range_v1_2` 只作为原始范围参考。

## 对用户问题的回答

结论：**你的判断基本成立，但要加一个限制。**

在道路坐标判定为非弯道的训练候选中，绝大多数高度变化确实只是很小的波动：

- z 去趋势后波动中位数约为 `0.0041 m`；
- `87.9%` 的非弯道训练候选小于等于 0.01 m；
- `93.2%` 小于等于 0.02 m；
- `95.2%` 小于等于 0.05 m。

因此，直路/非弯道事件里出现 `0.00x ~ 0.0x m` 的高度变化是正常现象，不能因为有零点零几米的 z 波动就判定为路外、上坡、下坡或异常。

## 它是不是“侧倾导致的质心高度变化”

从现有字段只能保守地说：**它和车身姿态/横滚变化有关，但不能严格证明就是质心高度变化。**

非弯道训练候选中，z 残差范围与这些指标的相关性为：

- 与 `roll_range_raw_v1_2` 的相关系数：`0.724`；
- 与 `peak_abs_roll` 的相关系数：`0.790`；
- 与 `peak_abs_ay` 的相关系数：`0.034`。

这说明小幅 z 波动更接近“横滚/姿态/悬架/车身运动伴随变化”，而不是单纯横向加速度大小。由于 `zx|z` 是仿真车辆坐标中的高度字段，不能直接等同于真实车辆质心高度，所以报告中不应写成强结论“质心高度一定变化”，更稳妥的说法是：

> 在直路/非弯道事件中，车辆高度 z 存在厘米级微小波动，并且与横滚姿态变化具有明显相关性。这类波动应视为车辆动态响应的辅助信号，而不是道路坡度或路外异常的直接证据。

## 对后续筛选规则的建议

1. `z_residual_range <= 0.02 m`：基本应视为正常微动，不应作为排除依据。
2. `0.02 m < z_residual_range <= 0.05 m`：仍可接受，需结合横滚角、横向加速度、速度和制动判断。
3. `0.05 m < z_residual_range <= 0.10 m`：进入轻度复核区，不能自动排除。
4. `z_residual_range > 0.10 m`：应重点复核，尤其要看是否存在路边、斜坡、坐标/道路切换或异常姿态。
5. 直路事件筛选不应使用“有无 z 波动”作为主规则；应以横滚、横摆、横向加速度、方向盘动作、速度/制动变化为主，z 只作为辅助证据。
