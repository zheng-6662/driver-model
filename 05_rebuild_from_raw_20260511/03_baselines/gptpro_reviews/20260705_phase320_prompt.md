## 我当前看到的可能问题

1. 第319版虽然加入了最低激活约束，但 `search_v319_config()` 的失败回退仍然会选“0校正、0损失”的配置，所以没有真正删除全不改。
2. 即使看非零激活配置，最大覆盖也远低于要求：整体最多1.54%，强方向盘最多0.87%，困难前20最多1.45%。
3. 这说明不是验证漂移，而是训练折外阶段就几乎没有可激活样本。
4. 候选资格条件可能太严，尤其强/困难通道里仍然要求：
   - `candidate_bad_prob <= bad_floor_hard`
   - `candidate_gain_hat >= gain_floor_hard`
   - `candidate_margin >= margin_floor_hard`
5. 但如果完全放开资格，可能会复制第317版普通样本误伤问题。
6. 另一个可能是候选排序目标错了：当前排序依赖预测收益和坏风险，但这些模型可能在强方向盘样本上把真正需要改的样本排低了。
