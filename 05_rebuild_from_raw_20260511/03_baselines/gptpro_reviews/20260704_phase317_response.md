5.4 避免候选排序不稳定的方法
之前候选排序不稳定，很可能是因为：
候选之间差异太小；
排序目标只看单一误差；
没有 no-op 约束；
门控过度依赖弱特征；
top-1 选择在边界样本上跳变。
第317版要做以下约束。
方法 1：候选 ID 固定
每个候选有固定 ID，例如：
C00 = no-op
C01 = scale_0.85
C02 = scale_1.15
C03 = scale_1.30
C04 = scale_1.50
C05 = shift_-0.25
C06 = shift_+0.25
...
不要每个 batch 动态重排候选 ID。
方法 2：训练用 soft oracle，不直接 hard top-1
不要直接把最优候选设为 1，其余设为 0。
用 soft oracle 能减少候选之间误差接近时的随机跳变。
方法 3：候选间要有足够差异
如果候选曲线之间差别很小，门控排序必然不稳定。
候选库构建后要计算：
候选两两平均距离
候选 oracle coverage
每个候选被选为 oracle top-1 的次数
删除几乎没人用或高度重复的候选。
方法 4：增加 no-op 优先约束
对低风险样本，要求 no-op 候选概率高：
只在低风险样本上使用。
这样普通样本不会被强行放大。
方法 5：评估 top-1 和 softmax 两种输出
第317版验证时同时报告：
softmax 加权输出
top-1 候选输出
如果 softmax 好但严重样本仍幅值压缩，说明加权又平均化了，应使用 top-1 或降低 softmax 温度。

6.6 主模型结构

6.9 训练方式
推荐训练流程

；

只选一个通过门槛的第317版；
最后只跑一次测试集。
6.10 关于训练集第316预测的防泄漏处理
最好使用 out-of-fold 预测训练 Stage 2：
把训练集 650 个样本分成 5 折
每折用另外 4 折训练一个第316结构模型
对当前折生成 y0
最终得到 650 个 out-of-fold y0
原因：
如果 Stage 2 看到的是第316版在训练集上的过拟合预测，它会学到不真实的校正规律。
如果当前代码库暂时不方便做 5 折，第317版可以先用第316训练集预测，但要加严：
Stage 2 小模型
较强 no-op 正则
候选数量不超过 20
早停只看验证集
不过正式结论建议以 out-of-fold 版本为准。

7. 第317版通过标准
第317版通过必须满足：
1. Val-All 平均误差不劣于第316版超过 0.5%
2. Val-Normal 平均误差退化不超过 1.0%
3. Val-Strong-Steer 平均误差改善至少 3.0%
4. Val-Hard-Top20 平均误差改善至少 5.0%
5. Val-Hard-Top10 平均误差改善至少 8.0%
6. 幅值严重低估比例下降至少 20%
7. Val-All 中恶化超过 10% 的样本比例不超过 15%
8. Val-Normal 中恶化超过 10% 的样本比例不超过 10%
如果旧第307版在验证集上优于第316版，则全局门槛应改为：
Val-All <= 旧第307版 Val-All * 1.005
不能只拿第316版作为低标准。
8. 失败后的下一步判断
第317版失败后，不要盲目继续调权重，要根据失败类型分流。
情况 A：Val-All 变差，Hard 样本变好
说明校正范围过宽。
下一步：
提高高风险门控阈值
增强低风险 no-op 正则
降低 scale 最大值，例如从 1.75 降到 1.50
只允许 Val-Strong-Steer 或 High-Dynamics 组启用校正
情况 B：Val-All 不变，但 Hard 样本没改善
说明校正没有命中核心错误。
继续看 oracle 结果：
如果 oracle 候选能显著改善
说明候选库够用，门控选错。
下一步：
增强门控特征
加入事件类型标签
加入第316预测摘要
提高 KL(q || p) 权重
使用 top-1 训练或降低 softmax 温度
如果 oracle 候选也不能改善
说明候选库不够。
下一步：
增加残差原型数到 8
增加 shift 到 ±0.60s
增加 scale 到 2.00，但仅高风险启用
按早打、晚打、峰值回正、持续峰值分组建库
情况 C：幅值改善，相位仍错
说明幅值校正有效，但时间对齐不足。
下一步：
增加 phase head 权重
扩大 shift 网格
增加前 0.5s 曲线误差权重
加入 steer_rate_now、steer_acc_now、yaw_rate_slope 等相位特征
情况 D：相位改善，幅值仍小
说明时间对齐有效，但高幅值候选不够。
下一步：
增加 scale=2.0 候选
训练峰值幅度 A_hat
增加 peak-under loss
加入高幅值残差原型
情况 E：严重样本过冲
说明校正太激进。
下一步：
增加过估惩罚
限制 scale 最大值
对 A_pred / A_true > 1.5 的训练样本增加惩罚
普通样本强制 no-op
9. 最推荐的第317版命名和实验矩阵
建议第317版拆成以下实验编号：
317-A：第316 + 幅值候选门控
317-B：第316 + 相位候选门控
317-C：第316 + 幅值 + 相位候选门控
317-D：第316 + 幅值 + 相位 + 残差原型候选门控
最终主推：
第317-D
但只有当 317-D 同时满足全局无伤和困难样本改善门槛，才进入测试集。
10. 最终建议
第317版的核心方案应是：
不要继续过滤；不要只加权；不要重写主模型。
冻结第316版，增加一个只用锚点前信息和第316预测摘要的二阶段候选校正器。
候选显式覆盖幅值放大、时间平移和峰值残差三类错误。
验证集用全局无伤 + 普通无伤 + 强方向盘改善 + 困难样本改善四重门槛。
这版如果成功，能证明问题主要来自候选表达和门控选择。
如果失败，也能明确定位是：
候选库覆盖不足
还是门控选不准
还是锚点前信号本身不足以预测后续强动作
这比继续筛样本或继续调损失函数更有实验价值，也更符合当前毕业论文中“从样本边界清理到模型机制修正”的研究逻辑。
