# 第317版行动项

## 目标

在第315版保留清单和第316版完整重训结果基础上，修正保留下来的严重样本中的幅值压缩、相位错位和极端峰值跟随不足，同时保证普通样本不明显退化。

## 数据边界

1. 使用第315版保留清单。
2. 训练、验证、测试保留事件分别为 650、211、222。
3. 84 个隔离事件不参与训练、验证选模或测试主统计。
4. 测试集只在最终固定方案后报告，不参与任何参数选择。

## 第317版最小实验

1. 读取第316版基础预测，作为基础曲线。
2. 从锚点前车辆信号提取统计特征：
   - 当前方向盘角和方向盘角速度；
   - 近 0.3 秒、0.5 秒、1.0 秒方向盘角速度峰值；
   - 方向盘角加速度和变化一致性；
   - 当前横摆角速度、横向加速度、车速；
   - 近 0.5 秒横摆角速度和横向加速度斜率；
   - 第316版预测曲线的峰值幅度、峰值时间、首段斜率和曲线能量。
3. 构建候选曲线库：
   - 原预测候选；
   - 幅值缩放候选：0.85、1.15、1.30、1.50、1.75；
   - 时间平移候选：负0.40秒、负0.25秒、负0.10秒、正0.10秒、正0.25秒、正0.40秒；
   - 幅值和平移组合候选：1.30配负0.25秒、1.30配正0.25秒、1.50配负0.25秒、1.50配正0.25秒；
   - 残差原型候选：先从训练集残差中聚 4 类，每类生成 1 个候选。
4. 训练小型门控校正器：
   - 输入为锚点前统计特征和第316版预测摘要；
   - 输出为候选权重、是否启用校正的门控分数；
   - 普通样本增加原预测优先约束；
   - 高风险样本增加峰值低估惩罚。
5. 同时评估两种输出：
   - 候选加权输出；
   - 候选单选输出。

## 验证通过标准

1. 验证集全部样本平均误差相对第316版退化不超过 0.5%。
2. 验证集普通样本平均误差退化不超过 1.0%。
3. 验证集强方向盘样本平均误差改善至少 3.0%。
4. 验证集困难前20个样本平均误差改善至少 5.0%。
5. 验证集困难前10个样本平均误差改善至少 8.0%。
6. 幅值严重低估比例至少下降 20%。
7. 验证集全部样本中误差恶化超过 10% 的比例不超过 15%。
8. 验证集普通样本中误差恶化超过 10% 的比例不超过 10%。

## 失败分流

1. 如果整体变差但困难样本变好：收紧高风险门控，增强普通样本原预测约束，降低最大幅值缩放。
2. 如果整体不变但困难样本没改善：检查候选最优上限。候选最优能改善则改门控；候选最优也不能改善则扩充候选库。
3. 如果幅值改善但相位仍错：增加相位平移候选和相位损失。
4. 如果相位改善但幅值仍小：增加峰值幅度监督和峰值低估惩罚。
5. 如果出现过冲：增加过估惩罚，限制最大幅值缩放。

## 产物要求

1. 生成第317版中文报告。
2. 输出验证分组表、测试分组表、逐样本指标表。
3. 输出候选使用次数、候选最优次数、门控命中率。
4. 输出幅值比、峰值时间误差、低估比例、过估比例。
5. 输出第316版、第317版和旧第307版的同集对照。
