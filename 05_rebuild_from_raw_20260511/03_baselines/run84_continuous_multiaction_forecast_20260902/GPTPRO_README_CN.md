# GPTPro 阅读入口：Run84 连续多动作预测

## 请先看结论

本目录是一次已经完成并通过本地独立验证的连续预测实验：使用过去 2 秒车辆—操作序列，预测未来 1 秒方向盘、制动和加速踏板相对当前值的完整变化曲线，车速变化只作辅助输出。

主结果不是“可以立即个体化”。ExtraTrees+Transformer 残差融合在全部连续窗口上相对保持模型改善 10.19%，38/38 名驾驶员获益；但普通窗口 MAE 恶化 6.12%，超过预先冻结的 2% 伤害上限，因此最终结论是暂缓进入个体化阶段。

9. `validation.json`：最终 103 项验证结果。

## 必须保留的解释边界

- 训练与测试在外层按驾驶员隔离；同一 recording 不跨训练和测试。
- 历史 20 Hz 输入使用查询时点及以前最近原始样本，未来监督曲线单独离线插值。
- 残差模型的训练基础预测来自外层训练人口内部、按驾驶员隔离的 3 折 ExtraTrees OOF，不是同样本拟合值。
- 未来动作只用于训练权重和评分标签，不决定测试窗口是否进入。
- 联合主指标改善主要来自方向盘；制动与加速单通道 MAE 仍未超过当前值保持。
- 普通窗口 MAE 伤害是本轮停止个体化的直接原因，不能用 pooled 指标、RMSE 改善或某个子集收益覆盖。

## 希望 GPTPro 重点回答的问题

在不加入驾驶员个人历史、生理数据、大型 Transformer、完整车辆响应模型或未恢复刺激语义的前提下：

1. 如何最小化普通窗口中的小幅非零偏移，同时尽量保留动作已开始窗口和距离触发人口的收益？
2. 应优先采用训练侧普通窗口残差收缩、可解释的过去状态门控，还是按动作通道拆分“学习模型/保持模型”组合？
3. 如何让制动和加速通道至少不劣于保持模型，而不通过未来动作筛选测试人口？
4. 高动态但动作尚未明显开始的 6106 个窗口应采用怎样的无伤害约束和独立停止规则？
5. 在普通窗口伤害门通过以前，是否同意继续暂缓个体化？若不同意，请明确指出需要修改哪一条预注册门以及科学理由。
