# v275 stable bio consensus override

## 本轮目的

- v274 的单模型 sparse override 在 test-best diagnostic 上有极小改善，但 val 选择无法泛化。
- v275 改为多生理视角一致投票：多个 raw_set / pred_col 支持同一个非 latest 锚点时才覆盖。
- 选择规则同时约束 val bad_top10、val all、val normal、val strong_steer 与 val observe_later_like，避免只对少数样本过拟合。

## 判读

- val 选择出的 stable consensus 策略仍未低于 fixed wait-latest。
- 如果 test-best diagnostic 低于 fixed wait-latest 但 val 策略不低于，说明生理一致性仍主要是事后可见信号，不是稳定可部署规则。
- 这轮不是放弃生理，而是检验生理能否作为车辆不确定性下的稳定辅助证据。
