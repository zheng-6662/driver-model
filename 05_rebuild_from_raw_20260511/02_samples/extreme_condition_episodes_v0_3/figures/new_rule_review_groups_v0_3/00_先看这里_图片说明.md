# 新规则复核图片目录说明

这个目录已经按新人工规则把代表图分好。建议不要从原始 review_panels 目录乱翻，先按这里的顺序看。

## 推荐查看顺序

1. `00_最先看_强车身风险候选_可能可抢救`：最重要，很多原来 excluded 的样本可能属于真实极限姿态样本。
2. `05_轻微转向或普通对照_优先排除出极限主线` 和 `06_轻微或坐标风险_优先排除`：对照你第一张截图，确认哪些是直线保持微调或普通驾驶。
3. `01_明确极限主样本_可作为标尺`：建立极限主样本的判断标尺。
4. `02_弱响应或保守响应_车身强但方向盘不大`：对照你第二张截图，判断保守驾驶员样本是否应保留。
5. `03_延迟响应_车身先强方向盘后动`、`04_弱延迟响应_边界可保留`、`07_边界待复核_规则仍拿不准`：后续再看。

## 每张图建议你标什么

- `KEEP_EXTREME_MAIN`：车身动态明显，方向盘响应也明显。
- `KEEP_WEAK_CONSERVATIVE`：车身动态明显，但方向盘幅度不大或没有明显回正。
- `KEEP_DELAYED`：车身动态明显，但方向盘响应延迟。
- `NORMAL_CONTROL`：普通弯道、普通驾驶或直线保持微调。
- `RISK_POOL`：看起来可能有用，但坐标/窗口/锚点有风险。
- `EXCLUDE`：明显不是极限/近极限工况。
