## v253a state-signal disambiguation audit：生理/驾驶风格是否能降低未来分叉

在用户提出“接下来是时候介入生理信号和驾驶风格”之后，做了 v253a 审计。本轮没有训练新预测模型，而是沿用 v252 的近邻未来分叉框架，检查加入生理/驾驶风格状态后，test 样本在同 delay train 近邻中的未来分叉是否下降。

核心目的：

- 不直接把生理/风格拼进模型训练，先看它们是否真的能降低“同输入多未来”的歧义。
- 避免旧 style 表和当前样本口径不一致造成错误回贴。
- 确认所有状态窗口都是 observation 前可用，不使用标签未来。

主要处理：

- 旧 stage04 style 表匹配审计：`sample_id` 交集 `0`，`event_uid` 交集 `0`，`subject+session+anchor` 匹配 `0`，因此不能直接复用旧 style 表。
- 当前样本重新提取驾驶风格：从 raw vehicle CSV 提取 `last60_guard3`，窗口为 `[observation_s-63, observation_s-3]`，覆盖 `7002/7002`，不使用 observation 后未来，不重叠直接输入最后 3 秒。
- 当前样本提取生理信号：从 `physio_features_1hz.csv` 提取 `pre5_pre2` 和 `pre2_0`，recording 覆盖率 `0.919`，不使用 observation 后未来。

主要结论：

- bad_top10_v250 all-delay 上，vehicle-only 的 query-vs-neighbor future RMSE 是 `1.062711`，仍是所有组中最低。
- `vehicle_plus_style_w0.25` 为 `1.063706`，几乎持平但没有改善。
- `vehicle_plus_style_w0.50` 为 `1.086755`，变差。
- `vehicle_plus_physio_recent_w0.25` 为 `1.070286`，变差。
- `vehicle_plus_physio_recent_w0.50` 为 `1.131109`，明显变差。
- `vehicle_plus_style_physio_w0.50` 为 `1.146586`，明显变差。
- 0ms bad_top10_v250 上，style_w0.25 有很小改善 `-0.009661`，但 all-delay 不成立，且 all/strong/observe_later 多数变差，不能作为路线证据。
- 近邻 same subject / same recording rate 均为 `0`，本轮结果不是身份或同记录匹配污染造成的。

解释：

- 生理和驾驶风格可以介入，但当前“直接拼接到输入空间做近邻/确定性预测”的方式没有降低未来分叉。
- 这不等于生理/风格无效，而是说明它们更适合作为概率/多模态模型里的条件变量、置信度校准或不确定性估计信号。

## v252 input-similarity future-divergence audit：相似输入后续真实轨迹是否分叉

在用户判断“锚点前有效信息不多、样本与样本之间很像，但锚点后行为可能大不一样”之后，补做了 v252 可辨识性审计。本轮不训练模型、不调通道、不删样本，只固定 `v250_minimal_lateral7` 输入口径，对每个 test rolling sample 在同 delay 的 train 样本里找输入近邻，然后比较近邻的真实未来 steering_delta 是否分叉。

核心目的：

- 直接验证“相似输入是否对应多种未来”。
- 判断差样本是否主要来自锚点前信息不足，而不是模型结构不够复杂。
- 把近邻未来分叉程度和 v250/v241 的真实误差做相关分析。
- 输出 casebook 图，给人工看“锚点前像、锚点后散开”的具体样本。

主要结论：

- 全 test rolling sample：`N=1104`，近邻未来两两 RMSE 均值 `0.707`，query-vs-neighbor 未来 RMSE 均值 `0.686`。
- 当前 v250 bad_top10 样本：`N=111`，近邻未来两两 RMSE 均值升至 `0.837`，query-vs-neighbor 未来 RMSE 均值升至 `1.063`。
- 0ms 原始锚点更明显：全体近邻未来两两 RMSE `0.836`，v250 bad_top10 0ms 为 `0.963`，query-vs-neighbor 未来 RMSE 为 `1.148`。
- `neighbor_future_to_query_mean_rmse` 与 `tail_rmse_v250` 的 Spearman 为 `0.495`，而 `neighbor_input_distance_mean` 与 `tail_rmse_v250` 的 Spearman 仅 `0.047`。
- 解释：误差不是主要来自“输入近邻找得不近”，而是输入近邻即使相似，未来真实行为也会分叉。
- 高未来分叉 q75 覆盖 all-delay v250 bad_top10 的 `44.1%`，覆盖 0ms v250 bad_top10 的 `56.7%`。说明未来分叉是重要原因，但不是唯一原因。

典型样本：

- `rjy_Entity_Recording_2025_09_28_19_51_44_v108_039` 0ms：input distance mean `0.278`，但 query-vs-neighbor future RMSE `1.658`。
- `tyy_Entity_Recording_2025_09_28_14_40_01_v108_012` 0ms：v250 tail RMSE `1.843`，近邻未来两两 RMSE `1.380`。

## v253b physio/style state tie-break audit：车辆相似候选池内用生理/风格重排序

用户进一步明确：希望生理状态提供的是“驾驶员区别/状态区别”，即单看车辆数据时锚点前样本可能很像，但不同驾驶员或不同生理状态可能导致锚点后行为不同。因此今天在 v253a 后补做 v253b，方法不再是把生理/风格简单拼接到全局输入距离，而是先用 vehicle-only 在同 delay train 样本中找 top60 车辆相似候选池，再只在这个池内用生理/风格距离做 tie-break。

核心边界：

- 不训练新预测模型。
- 不修改 v250/v252/v253a。
- 真实未来只用于诊断 tie-break 是否选对，不作为部署输入。
- 当前 split 是 subject-disjoint：test subject 为 `cwh/lx/rjy/tyy`，train subject 为 `byx/gf/hzh/jy/xst/yyl/yzy/zt/zx/zxy`，因此不能验证同一驾驶员个体记忆，只能验证跨驾驶员状态相似性。

主要结果：

- v250 bad_top10 all-delay：
  - vehicle_rank1 selected future RMSE `0.9934`。
  - style_nearest `1.1043`。
  - physio_recent_nearest `1.1076`。
  - physio_guarded_nearest `1.1930`。
  - style_physio_nearest `1.2733`。
  - oracle_best_future_in_vehicle_pool `0.3678`。
- 全体 all-delay：
  - vehicle_rank1 `0.5814`。
  - style_nearest `0.7757`。
  - physio_recent_nearest `0.7895`。
  - physio_guarded_nearest `0.8034`。
  - style_physio_nearest `0.7953`。
  - oracle `0.1846`。
- 候选池内距离-未来误差相关：
  - bad_top10_v250 中 vehicle mean Spearman `0.152`。
  - style `0.026`。
  - physio_recent `-0.008`。
  - physio_guard `-0.022`。
  - style+physio `-0.002`。

解释：

- oracle 很强，说明车辆相似候选池里确实经常存在更接近 query 未来的样本。
- 但当前生理/风格距离不能把这些更好未来选出来；它既没有稳定降低 selected future RMSE，也没有形成“距离越近未来越近”的相关关系。
- 因此 v253b 不等于“生理没用”，而是说明当前 1Hz 生理统计 + last60_guard3 风格特征，作为手工距离或简单拼接输入时不可用。

## v254a physio deep signal audit：从简单拼接转向深层挖掘生理数据

用户明确指出：并不是想把生理数据简单拼接进车辆输入，而是希望深层挖掘生理数据，让生理状态提供驾驶员区别或状态区别。因此今天在 v253b 之后继续做 v254a，目标不是训练新轨迹预测模型，而是先检查生理数据本身有没有可学习结构，以及这种结构是否和未来驾驶行为有关。

本轮方法：

- 复用 v252/v253 固定 rolling sample、split 和 vehicle input。
- 不训练轨迹预测模型。
- 使用 `physio_features_10hz.csv`，即从清洗后 200Hz 连续生理层派生的 10Hz 聚合特征。
- 对每个 rolling sample 提取锚点前多窗口：
  - `pre20_pre10`
  - `pre10_pre5`
  - `pre5_pre2`
  - `pre2_0`
- 每个窗口提取均值、标准差、分位数、range、abs_mean、RMS、首末值、首末差、斜率，并提取 recent 相对 earlier window 的差值。
- 构造诊断标签：
  - `future_cluster4/future_cluster6`
  - `high_future_abs_q75`
  - `high_future_range_q75`
  - `future_peak_sign`
  - `strong_steer_existing`
  - `bad_top10_v250_diagnostic`
- 诊断模型只在 train 拟合，val/test 只报告，不用 test 选模型或调特征。

数据覆盖与质量：

- 10Hz 生理 recording 覆盖率：
  - all `0.919`
  - test `0.897`
  - train `0.889`
  - val `1.000`
- 所有窗口 `uses_post_observation_rate=0`，没有使用 observation 后数据。
- 特征块维度：
  - vehicle_only：`268`
  - physio10hz_deep：原始 `840`，保留 `700`
  - physio1hz_v253a：原始 `209`，保留 `184`
  - vehicle_plus_physio10hz：保留 `968`
- HRV_RMSSD 基本不可用：train finite rate `0.063`，near-constant feature rate `1.0`。
- RESP_BPM 和 RESP_Amplitude 近常数比例偏高，不能当作可靠丰富动态特征直接使用。

核心结果：

- 生理对 subject/recording 的可分性很强，说明生理数据不是空的，里面确实有身份/记录/设备或个体状态结构。
- 但对未来行为标签的可分性很弱：
  - future_cluster4 top eta² 约 `0.015`。
  - high_future_abs_q75 top eta² 约 `0.020`。
  - strong_steer_existing top eta² 约 `0.023`。
- test 分类：
  - future_cluster4 macro-F1：vehicle_only `0.7317`，physio10hz_deep `0.2944`，physio1hz_v253a `0.2954`，vehicle+physio10hz `0.5020`。
  - high_future_abs_q75 macro-F1：vehicle_only `0.7112`，physio10hz_deep `0.4897`，vehicle+physio10hz `0.6239`。
  - high_future_range_q75 macro-F1：vehicle_only `0.6586`，physio10hz_deep `0.4616`，vehicle+physio10hz `0.6019`。
  - strong_steer_existing macro-F1：vehicle_only `0.6630`，physio10hz_deep `0.5482`，vehicle+physio10hz `0.5881`。
- test 回归：
  - future_peak_abs R²：vehicle_only `-0.0640`，physio10hz_deep `-2.6815`，physio1hz_v253a `-0.6691`，vehicle+physio10hz `-1.0844`。
  - future_range 和 future_mean_abs 也没有生理增量。

解释：

- v254a 进一步支持 v253b 的判断：问题不是“没有更细生理表”，而是当前窗口统计没有把生理身份/记录结构转化成行为预测信号。
- 生理信号目前更像记录/个体状态信号，而不是可以跨 subject 泛化的行为模式信号。
- 高维 10Hz 生理直接拼到 vehicle 后反而会让 test 分类下降，说明简单拼接会引入噪声或 subject-disjoint 分布偏移。
