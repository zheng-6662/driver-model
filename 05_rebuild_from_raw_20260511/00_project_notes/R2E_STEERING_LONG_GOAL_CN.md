一、最终目标

从原始车辆、生理、脑电 .csv 数据重新构建事件触发后的方向盘转角轨迹预测流程，建立一套可追溯、可复现、无泄漏、能解释物理响应的证据链。

最终需要回答：

1. 车辆历史和事件信息本身能预测到什么程度；
2. 连续驾驶风格是否提供车辆历史之外的个体差异信息；
3. 生理数据是否提供车辆历史和连续风格之外的驾驶员内部状态、运动准备、认知负荷、响应类型、困难样本或可靠性信息；
4. 如果生理数据有效，它更适合作为推理输入、训练教师、辅助任务、门控信号、响应类型判断，还是困难样本识别；
5. 如果生理数据当前无效，需要区分是信号本身无效、表示方式不对、融合方式不对、模型结构不适合，还是评价体系没有捕捉到它的作用；
6. 新流程模型能否比旧流程在整体误差、方向、幅值、错侧、尾段回正/漂移、反向修正、多段修正和困难样本上有明显提升。

这个目标不预设“生理数据一定有效”，也不预设“旧粗细双头结构必须保留”。旧流程只作为参考、对照和失败样本来源，不能再默认认为旧事件锚点、旧同步、旧标准化、旧生理处理、旧样本划分一定正确。

四、基本原则

1. 不先训练新模型，先做原始数据审计。
2. 不把旧流程结果当成默认真相。
3. 所有样本必须能追溯到原始文件、原始时间戳、事件锚点、输入窗口、标签窗口和信号质量。
4. 所有特征、标准化、基线校正、风格提取和生理特征提取都必须证明没有测试集泄漏。
5. 评价不能只看 RMSE，必须覆盖方向、幅值、错侧、尾段、峰值时间、反向修正、多段修正、困难样本、分被试表现。
6. 连续驾驶风格和生理数据的有效性必须通过强车辆基线、置乱对照、分被试结果和物理指标共同验证。
7. 如果某条路线只带来很小 RMSE 波动，但不能改善物理错误和困难样本，不能升级为主线。
8. 每个阶段都要有中文报告、表格、图、产物索引和能向老师解释的结论。
9. 关键代码或文档修改后要 Git 提交；不要把服务器密码写入日志、报告或代码。
10. 不冲突的任务可以并行执行，以提高效率；但数据审计、样本规则和无泄漏协议是后续模型训练的前置条件。
11. 执行长期任务时，如果有后台任务在跑，必须在 PROJECT_STATUS_CN.md 和 SERVER_RUNS_CN.md 中写清楚，不能让用户不知道当前跑到了哪里。
12. 如果任务失败，不要只写“失败”，必须写明失败命令、失败原因、影响范围、是否需要重跑、下一步修复方案。

六、阶段划分

阶段 0：旧流程冻结与重建准则

目标：
冻结旧流程继续堆模型的路线，把旧流程降级为参考材料、失败样本库和历史对照。

任务：
1. 整理旧流程中可以参考的内容：车辆历史强基线、连续风格迹象、脑电教师迹象、肌电候选、困难样本归因、预测图、旧代码入口。
2. 整理旧流程中不能默认相信的内容：事件锚点、时间同步、200Hz 对齐、标准化、生理状态标签、肌电窗口、脑电教师结论、随机切分、RMSE 排名。
3. 建立新流程硬性规则：无泄漏、可追溯、可复现、强基线、物理指标、分被试验证。
4. 输出旧流程参考清单和旧流程风险清单。
5. 初始化执行透明化文件：PROJECT_STATUS_CN.md、TASK_QUEUE_CN.md、ARTIFACT_INDEX_CN.md、SERVER_RUNS_CN.md、daily_logs。

完成标准：
- 形成中文说明：哪些旧结论可以参考，哪些必须重新验证；
- 明确新流程不再直接继承旧处理结果；
- 明确新流程目录和产物组织方式；
- 用户能通过 PROJECT_STATUS_CN.md 看到当前进度。

停止规则：
如果旧代码、旧日志和原始数据之间无法建立基本映射，例如被试 ID、记录 ID、事件 ID 完全无法对应，则暂停建模，先进入数据映射修复。

阶段 1：原始数据审计

目标：
回答三个问题：
1. 原始数据完整吗；
2. 时间轴和模态同步可信吗；
3. 是否能构建无泄漏、可追溯的事件样本。

任务：
1. 扫描原始车辆、生理、脑电 CSV，生成文件清单和哈希。
2. 读取每个 CSV 的列名、行数、时间范围、缺失率、重复时间戳、异常值。
3. 建立被试、记录、模态完整性矩阵。
4. 审计 StorageTime 连续性、采样率、时间 gap、重复点、时间漂移。
5. 审计车辆、生理、脑电之间的时间重叠和可能偏移。
6. 抽样绘制车辆、生理、脑电原始波形和采样间隔分布。
7. 初审事件锚点来源、道路信息和事件设定，与旧日志交叉核对。
8. 审计预测窗口是否覆盖完整方向盘响应。
9. 审计未来信息泄漏风险：输入窗口、标签窗口、生理窗口、风格窗口、标准化、基线校正。
10. 审计生理信号质量：ECG、EMG、EDA、RESP 的缺失、饱和、异常尖峰、低质量片段。
11. 审计脑电质量：通道缺失、极端异常值、伪迹、加速度干扰。
12. 特别审计 EMG 是否可能包含事件后动作结果。如果 EMG 时间窗已经接近主响应阶段，要标记为可能动作结果泄漏，只能作为早期响应预测或上限分析，不能直接证明内部状态有效。
13. 每完成一个子审计，就更新 PROJECT_STATUS_CN.md、TASK_QUEUE_CN.md 和 ARTIFACT_INDEX_CN.md。

输出：
- raw_file_inventory.csv
- raw_schema_report.csv
- subject_session_modality_matrix.csv
- timestamp_continuity_report.csv
- sampling_rate_report.csv
- modality_overlap_report.csv
- signal_quality_report.csv
- eeg_artifact_report.csv
- leakage_risk_report.csv
- raw_data_audit_summary_cn.md
- stage01_user_summary_cn.md
- figures/audit/ 下的时间线图、采样间隔图、原始波形图、异常示例图、模态重叠图。

完成标准：
- 所有可读取原始 CSV 都完成文件和字段审计；
- 每个被试/记录/模态是否可用有明确标记；
- 车辆、生理、脑电时间轴是否可同步有明确判断；
- 事件锚点和预测窗口是否值得进入样本构建有明确判断；
- 所有已知泄漏风险被列出并给出处理建议；
- 用户可以通过 stage01_user_summary_cn.md 看懂目前发现和下一步建议。

停止规则：
出现以下情况必须停在数据阶段：
- 大量原始文件缺失或无法读取；
- 车辆与标签目标无法稳定定位；
- 时间戳无法解析或严重不连续；
- 车辆、生理、脑电几乎没有有效重叠；
- 事件锚点来源无法解释；
- 输入窗口不可避免包含标签未来；
- 标准化或基线校正无法避免测试集泄漏。

并行策略：
文件扫描、字段审计、时间戳审计、生理质量审计、脑电质量审计、旧日志事件信息检索可以并行做；但最终进入阶段 2 前必须统一汇总。

阶段 2：事件锚点与样本清单重建

目标：
重新定义可追溯的事件样本，而不是直接继承旧 manifest。

任务：
1. 根据原始数据和旧日志重新整理事件锚点来源。
2. 为每个候选事件建立样本记录，包含被试、记录、道路、事件类型、锚点时间、输入窗口、标签窗口、可用模态、质量标记、泄漏风险。
3. 比较多个候选输入窗口和预测窗口，例如保留旧 2 秒窗口作为主对照，同时评估 1 秒、3 秒或覆盖完整响应的窗口。
4. 构建 samples_master.csv/jsonl。
5. 构建 split_table，至少包含随机样本切分、session-level 切分、subject-level 或留一被试切分的可行性说明。
6. 生成 dataset_version_card，记录每个数据版本的规则、排除样本、质量阈值和统计数量。
7. 输出 stage02_user_summary_cn.md，并更新总进度看板。

完成标准：
- 每个样本能追溯到原始文件和时间范围；
- 每个样本有明确 causal setting：事件发生时预测完整未来，还是早期观察后预测剩余轨迹；
- 每个样本有质量标签和泄漏风险标签；
- 数据划分规则明确，测试集统计不参与训练标准化和特征学习。

停止规则：
如果无法构建无泄漏样本清单，不能训练模型。

阶段 3：无学习基线与强车辆基线

目标：
先确认纯车辆和事件信息能做到什么程度，再谈风格和生理。

任务：
1. 建立无学习基线：零响应、保持当前值、历史趋势外推、同类事件平均轨迹。
2. 建立强纯车辆模型：车辆历史 + 事件/道路上下文。
3. 评估整体 RMSE、主响应误差、尾段误差、方向错侧、峰值幅值、峰值时间、反向修正、多段修正、困难样本。
4. 建立固定预测图协议，固定样本集和坏样本集，不只挑好看的图。
5. 做小样本过拟合测试：如果训练集都拟合不好，说明模型容量或优化有问题；如果训练集能拟合但测试不行，说明泛化或输入信息不足。
6. 输出 stage03_user_summary_cn.md，并更新总进度看板。

完成标准：
- 有无学习基线、纯车辆基线和强车辆基线；
- 旧流程 E2/E5A/E10C 等只作为历史对照；
- 新指标和预测图能够解释“趋势像但物理意义不对”的问题。

停止规则：
如果强车辆基线不稳定或评价指标无法解释预测图问题，不能进入风格和生理阶段。

阶段 4：连续驾驶风格有效性验证

目标：
判断连续驾驶风格是否真的提供个体差异信息，而不是驾驶员编号、道路类型、事件类型或标签泄漏代理。

任务：
1. 重新定义连续驾驶风格的提取来源，只允许使用事件前、训练期可用、无未来标签的信息。
2. 与驾驶员 ID 编码做对照。
3. 做风格置乱：同被试内置乱、跨被试置乱、跨 session 置乱。
4. 做分被试和跨被试评估。
5. 分析风格是否改善大幅响应、方向、幅值、尾段、困难样本，而不是只改善整体 RMSE。
6. 检查风格是否和道路/事件分布高度耦合。
7. 输出 stage04_user_summary_cn.md，并更新总进度看板。

可以说连续驾驶风格有效的条件：
- 相比强车辆基线有稳定提升；
- 至少在两类切分中成立；
- 置乱后收益明显下降；
- 不只是驾驶员 ID 的替代品；
- 至少改善一部分物理指标或困难样本。

如果只在随机样本切分下有效，只能说：
“连续风格在同分布样本切分下有拟合增益，暂不能证明跨被试泛化价值。”

阶段 5：生理信号角色验证与辅助任务

目标：
重新判断 ECG/心率、EDA/皮电、EMG/肌电、EEG/脑电、RESP/呼吸各自适合承担什么角色。

原则：
不要默认生理数据直接拼接到轨迹回归模型。

建议角色：
1. ECG/心率：更适合作为压力、负荷、唤醒水平、困难样本风险或可靠性门控，不应一开始直接承担瞬时方向盘主峰预测。
2. EDA/皮电：更适合作为慢变化唤醒、紧张、认知负荷、困难样本识别或门控，不应直接预测轨迹细节。
3. EMG/肌电：最可能与运动准备、操纵意图、方向盘动作相关，但必须严查是否包含事件后动作结果。若窗口无泄漏，可作为部署期候选输入；若窗口接近响应阶段，只能作为早期观察后预测剩余轨迹或上限分析。
4. EEG/脑电：优先作为训练期教师、辅助监督、响应类型/方向/大幅响应/延迟判断来源，不优先作为部署期主输入。
5. RESP/呼吸：优先级低于 ECG、EDA、EMG、EEG，可作为状态或质量辅助信号保留。

任务：
1. 对每个生理模态做质量审计和置乱对照。
2. 做单模态输入、单模态辅助任务、单模态门控的对照。
3. 做生理时序编码，而不是只压成静态上下文向量。
4. 做任务相关辅助标签：方向、大幅响应、反向修正、多段修正、尾段漂移、困难样本风险。
5. 做生理跨人置乱、时间错位、窗口错位对照。
6. 对比生理直接输入、辅助任务、门控、训练教师的作用差异。
7. 输出 stage05_user_summary_cn.md，并更新总进度看板。

可以说某类生理数据有效的条件：
- 在强车辆 + 连续风格基线之上有可复现增益；
- 置乱或时间错位后增益消失；
- 至少改善某些物理指标、响应类型或困难样本；
- 分被试结果不是只靠单一被试撑起来；
- 没有未来信息泄漏或动作结果泄漏。

如果只改善很小 RMSE，不改善方向、幅值、尾段、困难样本或置乱对照，则不能说生理有效，只能说“当前表示下没有形成强证据”。

阶段 6：结构化轨迹建模

目标：
解决旧模型“趋势像但方向、幅值、错侧、尾段物理意义不对”的问题。

优先模型路线：
1. 普通轨迹模型：强基线。
2. 响应分解模型：先预测方向、幅值、启动延迟、峰值时间、响应类型，再预测轨迹。
3. 关键点 + 残差轨迹模型：先预测主峰、尾段回正点、零线穿越，再预测残差。
4. 多假设轨迹模型：输出多个可能响应，避免把多种合理未来平均成一条幅值偏小的轨迹。
5. 多模态时序融合模型：车辆历史、生理时序、风格信息分支编码，再融合。
6. 可靠性与困难样本模型：识别哪些样本不可稳定预测，哪些样本需要生理或多假设。

完成标准：
- 新模型不仅看 RMSE，还必须改善方向、幅值、错侧、尾段、反向修正、多段修正或困难样本；
- 每个模型都有和强车辆基线、连续风格基线、生理候选路线的公平对照；
- 不把结构复杂化当成结论，必须有消融和置乱验证；
- 每个候选模型都有用户查看版中文解释和预测图索引。

阶段 7：多假设/概率轨迹模型

目标：
处理相同历史输入可能对应多种驾驶响应的问题，减少平均化轨迹。

任务：
1. 建立多候选输出模型。
2. 评价 top-1、best-of-K、概率校准、不确定性和固定图。
3. 检查多候选是否真正覆盖大幅响应、反向修正、多段修正，而不是产生多个相似平滑轨迹。
4. 判断连续风格和生理数据是否能改善候选选择或不确定性判断。
5. 输出 stage07_user_summary_cn.md，并更新总进度看板。

完成标准：
- 多候选模型在困难样本、反向修正、多段修正和大幅响应上有实际改善；
- 不只依赖 best-of-K 上限，必须报告实际可用选择策略。

阶段 8：EEG 教师蒸馏与多模态强模型

目标：
在数据、样本、评价和强基线都可信之后，重新评估脑电教师和多模态融合。

任务：
1. EEG 作为训练期教师，学生推理时不使用 EEG。
2. EEG 教师重点用于响应类型、方向、大幅响应、延迟、困难样本，而不是简单拟合整条轨迹。
3. EMG 等可部署信号作为学生输入候选。
4. 比较直接输入、教师蒸馏、辅助任务、门控和多模态融合。
5. 所有生理路线必须做置乱、错位、分被试和困难样本验证。
6. 输出 stage08_user_summary_cn.md，并更新总进度看板。

完成标准：
- EEG 教师或生理融合能在强车辆 + 连续风格基线之上提供稳定增量；
- 改善不只来自普通样本；
- 能说明每个模态在什么子问题上起作用。

阶段 9：证据链汇总、失败样本复盘和最终报告

目标：
形成老师和论文都能理解的最终主线。

输出：
1. 新流程数据审计报告；
2. 样本 manifest 和数据版本卡；
3. 无学习、纯车辆、车辆 + 风格、车辆 + 风格 + 生理、教师蒸馏、多假设模型统一对照表；
4. 分被试结果；
5. 分道路/事件类型结果；
6. 分响应类型结果；
7. 固定预测图；
8. 困难样本图谱；
9. 生理有效性证据链；
10. 连续风格有效性证据链；
11. 最终推荐主线和不能下的结论清单；
