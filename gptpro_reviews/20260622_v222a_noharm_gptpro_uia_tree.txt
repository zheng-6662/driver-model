1. 先给你一个明确决策
不要再做：单一大 Transformer 直接吐完整方向盘曲线。
原因很明确：前面很多实验已经反复证明，端到端完整曲线预测容易把强反应压平。v218 把峰值保护和强反应权重内化进训练后，反而明显退化，这说明“继续加 loss、加大模型、加权强事件”不是稳定路线。
应该做：组合式模型。
也就是：
1. Transformer 只负责做时序编码，不要指望它独自解决全部问题。
2. 主输出不要只预测方向盘，还要同时预测未来车辆状态。
3. 机制标签不要单独变成论文主任务，而是作为辅助约束和解释模块。
4. 候选曲线不能硬切换，要软融合。
5. 峰值保护先做成保守、可控的模块，不要再强行塞进完整曲线训练损失。
6. 残差修正只做小修正，不要让它重新生成整条曲线。
一句话：v216/v217/v219 这条线应该继续，v218 这种“重训大模型 + 强峰值损失”暂时停止。

2. 下一版模型我建议这样拆模块
我建议你把下一版叫成类似：
v221/v222：机制感知的人车联合滚动预测模型
结构可以拆成 5 个部分。
A. 输入模块
保留现在最靠谱的输入：
• 锚点前 3 秒历史序列，0.1s 采样，约 31 × 11；
• 锚点后 2 秒道路曲率和高度预瞄，约 21 × 2；
• 滚动更新时间：0ms / 20ms / 40ms 分别建模或作为条件输入；
• 不要把真实未来峰值、真实未来误差、真实标签后验信息放进去。
生理和脑电先不要进主模型。它们可以作为后续解释章节，但不是现在救主模型的核心。
B. Transformer 编码器
Transformer 的定位是：编码人车历史状态和道路预瞄。
它不直接承担所有预测责任。输出一个共享状态向量，用给后面的多个头：
• 驾驶员行为预测头；
• 车辆状态预测头；
• 机制分类头；
• 候选曲线权重头；
• 残差修正头。
模型不要太大。这个数据量下，大模型很容易学成平均化或过拟合。
C. 联合预测头
主任务不再是“只预测方向盘”，而是：
未来驾驶员行为：
• 方向盘角；
• 方向盘角速度；
• 可选：制动、油门参与。
未来车辆状态：
• roll / vroll；
• ay；
• yaw 或 vyaw；
• vy / lateral dynamics；
• 也可以保留速度、横向速度等辅助状态。
v216 已经证明，联合预测比 steering-only 更有希望。你后面要沿着这个逻辑讲：驾驶员纠正不是孤立方向盘曲线，而是车辆状态变化下的人车耦合响应。
D. 机制辅助头
机制头不要当论文唯一主任务，但必须保留。建议至少预测这些事件级目标：
• 是否强方向盘反应；
• 是否反打 / 反转；
• 是否过零反转；
• 峰值幅度等级；
• 峰值出现时间；
• 后段是否继续变化；
• 是否多段纠正；
• 车辆响应强弱；
• 驾驶员响应到车辆响应的延迟。
这些头的作用有三类：
1. 帮助模型区分普通小幅样本和真正强事件；
2. 给候选融合提供权重；
3. 给论文提供解释性结果。
这里不要执着于纯 Transformer。v212-v214 已经说明，小样本下 RF / logistic / 表格强特征有时比小 Transformer 更稳。论文里完全可以说：深度编码器负责序列表示，机制判别采用轻量校准头，目的是提高小样本稳定性。
E. 候选曲线 + 软融合 + 峰值保护 + 残差修正
这是下一步最关键的模块。
候选可以包括：
1. 保守基线候选：类似 v183 或 v216 joint_equal；
2. 联合模型平均候选：类似 v217 的 avg_joint_focus；
3. 峰值保护候选：类似 peak_floor_090，但必须受机制概率约束；
4. v183-relative 残差候选：控制点/模板都尽量变成相对保守基线的小修正；
5. 轻量 Ridge / ElasticNet / 小 MLP 残差候选：类似 v219，但限制输出幅度；
6. 反转候选：只在反转概率较高时软参与，不能硬切换。
融合规则要保守：
没有足够证据时，退回保守基线；只有机制概率、候选收益预测和验证集表现都支持时，才允许使用激进候选。
这点很重要。前面很多失败不是候选没有好答案，而是选错候选会伤害普通样本。

v222 的训练目标
v222 的 loss 不要只用整体 RMSE。
建议这样写：

  + λ_tail · L_tail
  + λ_under · L_under
  + λ_resid · L_resid
  + λ_smooth · L_smooth
  + λ_noharm · L_noharm
每一项含义如下。
1. 整体曲线误差
复制

用 Huber 比 MSE 稳，因为强事件里容易有异常大峰值。
2. 后段误差
复制
L_tail = Huber(ŷ[t >= 1.0s], y[t >= 1.0s])
你项目里的很多问题都出在后 1 秒，所以后段必须单独加权。
3. 严重低估惩罚
只在真实强反应样本上启用：
复制

    L_under = max(0, 0.65 * true_peak_abs - pred_peak_abs)^2
else:
    L_under = 0
注意这里用 0.65 或 0.70，不要一上来用 0.90。
v218 的教训是：峰值损失太强会毁曲线。
4. 残差幅度惩罚
复制
L_resid = mean(r(t)^2)
防止残差头过度发挥。
5. 平滑惩罚
复制
L_smooth = mean((r(t) - r(t-1))^2)
防止残差头制造不合理振荡。
6. Do-no-harm 惩罚
对普通样本和低风险样本启用：
复制
L_noharm = max(0, error_final - error_conservative - margin)
意思是：
如果模型没有足够证据，就不要比保守基线更差。
