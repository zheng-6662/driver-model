# 生理信号到 G14 阶段整理包

这个目录用于暂停训练后回顾目前进展，重点回答：

- 连续驾驶风格是否有效；
- 脑电是否有用；
- 肌电、心率、皮电分别有没有价值；
- 为什么后面转向困难样本、响应类型和物理意义问题；
- G13/G14 为什么没有形成新主线；
- 结果图应该去哪看。

## 建议阅读顺序

1. 先读 `01_阶段进展总览_CN.md`。
   这是完整中文梳理，适合向老师汇报前先看。

2. 再看 `03_关键结果表_CN.csv`。
   这是所有关键版本的数字总表。

3. 看图时先打开 `selected_figures/`。
   我已经把最常看的代表图复制到了这里。

4. 如果要找全量图，打开 `02_结果图位置索引.csv`。
   这里记录了每类图的完整原始位置。

## 当前一句话结论

连续驾驶风格有效，脑电教师有效，肌电单信号有效；但当前模型最大的瓶颈已经从“有没有生理信号”转为“能不能预测出方向、幅值、后段回正/漂移、反向修正、多段修正等物理意义”。G13/G14 没有形成新主线，当前主候选仍然是 E5A/E6/E10C。
