# 补充说明：生理数据 + 粗细双头，但不加连续风格

整理时间：2026-05-11

用户指出：“生理数据 + 粗细双头，但不加连续风格”这个组合之前似乎跑过。核对后确认：确实跑过相关旧实验，但它们和当前 E3/E4/E10 这套三种子主表不是同一级别证据。

## 为什么之前没有放进当前主表

当前主表主要使用的是 2026/2027/2028 三种子结果，例如 E1、E2、E3、E4、E7C、E10A、E10B、E10C。

FAIR10 和 FAIR15 是旧单次结果：

- FAIR10 使用的是 PCA 状态，里面混有生理和脑电信息，不是现在的“语义生理状态”或单信号归因版本；
- FAIR15 使用的是基线校正后的生理状态，和 E3/E4/E10 的输入构造不同；
- 两者都只有旧单次结果，不是现在用于主结论的三种子复验结果。

因此它们可以回答：“之前是否跑过粗细双头 + 生理相关输入，但不加连续风格？”

答案是：跑过。

但它们不适合直接作为当前“生理信号最终有效性”的主表结论。

## 对当前结论的影响

这两个旧结果反而支持一个更清楚的判断：

1. 单独把旧生理状态接到粗细双头上，不加连续风格，效果不好。
2. 连续风格仍然是非常重要的基础输入。
3. 当前真正有价值的生理证据主要来自两条：
   - 脑电作为训练阶段教师信息；
   - 肌电单信号作为推理阶段可用输入。
4. 如果后续论文需要非常严格地隔离“生理数据是否独立于连续风格有效”，可以补做一组新的三种子实验；但从现有旧结果看，这条路线不太像最优先突破口。
