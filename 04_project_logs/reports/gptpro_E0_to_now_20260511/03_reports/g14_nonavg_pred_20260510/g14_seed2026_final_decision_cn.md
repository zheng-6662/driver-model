# G14 seed2026 最终判定：多候选轨迹和响应原型没有形成新主线

## 1. 本轮为什么做

用户指出当前预测图里很多结果只是趋势相似，但方向、幅值、零线两侧意义、尾段回正和困难样本仍然不理想。因此 G14 不再继续做单条平均轨迹的小修小补，而是尝试让模型先理解响应类型，再输出多条候选轨迹或基于训练集响应原型修正。

## 2. 已完成的版本

- G14A：连续驾驶风格 + 响应先判别 + 四候选轨迹，不加肌电。
- G14B：连续驾驶风格 + 肌电 + 响应先判别 + 四候选轨迹。
- G14C：G14B 基础上加入幅值和方向约束。
- G14D：连续驾驶风格 + 肌电 + 响应先判别 + 八候选轨迹。
- G14E：肌电 + 固定响应类型监督候选选择 + 四候选轨迹。
- G14F：肌电 + 训练集响应原型 + 原型残差修正。
- G14G：脑电教师 + 肌电 + 响应原型候选。
- G14H：G14F 基础上加入幅值和方向约束。

所有正式版本均在服务器完成 seed2026 完整 40 轮训练。G14G 使用重新训练的兼容脑电教师，因为旧恢复版脑电教师 checkpoint 的输入维度与当前 G14 代码不一致。

## 4. 困难样本结果

G11 困难样本上，E10C 仍然是当前最强参照，RMSE 为 `0.6991`。G14C 为 `0.7120`，好于 E6/E5A，但仍不如 E10C。G14G 为 `0.7268`，没有把它的尾段优势转化成困难样本整体收益。

这说明当前瓶颈不是简单地“输出多条轨迹”就能解决，而是模型还不能在推理前稳定判断当前样本到底属于哪种响应类型，以及应该选哪个候选。

## 5. 对肌电和脑电教师的判断

肌电仍然有价值。G14B 明显好于 G14A，说明肌电在多候选结构中依然提供了信息。但 G14B/G14C 没有超过 E10C，说明当前多候选结构没有把肌电价值放大。

脑电教师仍然有价值。G14G 的尾段误差 `0.3477` 是本轮 G14 最好，也好于 E5A/E6/E10C 的尾段结果。这说明脑电教师 + 肌电 + 响应原型对尾段有帮助。但它整体 RMSE 没有超过现有强基准，G11 困难样本也没有同步改善，所以不能直接升级为新主线。

## 6. 当前结论

本轮 G14 没有形成新的强主线。当前主候选仍然应保持为：

- 无脑电推理路线：E5A / E6。
- 允许肌电推理路线：E10C。
- G14G：作为尾段改善和脑电教师作用的诊断证据保留，不直接补三种子。

不建议直接补 G14A-H 的 seed2027/2028，因为 seed2026 已经显示它们没有达到升级标准。继续补三种子只会验证“整体不够强”的结论，性价比不高。

## 7. 下一步建议

如果继续 G14，下一步不应该继续堆候选数量，也不应该继续盲目叠加约束。更合理的是先做归因：

1. 为什么 G14G 尾段变好，但整体 RMSE 和 G11 困难样本没有同步变好。
2. 为什么 G14E 幅值不足下降，但尾段漂移风险升高。
3. 当前候选选择头是否真的学到了响应方向、幅值等级和响应形态。
4. 是否需要把响应类型判别拆成更明确的分类任务，再把分类结果用于轨迹预测。
5. 是否要把相似历史事件作为候选来源，而不是完全依赖模型内部生成候选。
