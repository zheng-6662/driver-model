## 第一轮候选
- G13A：连续风格 + 响应类型辅助学习。目的：验证只增加响应类型监督，是否能让模型更理解大幅、反向、多段、晚峰等响应形态。
- G13B：连续风格 + 肌电 + 响应类型辅助学习。目的：验证肌电和响应类型监督一起使用时，是否比 E10C 更稳定。
- G13C：连续风格 + 肌电 + 响应类型影响轨迹预测。目的：让模型先预测响应类型，再把这个判断反馈给轨迹预测头，检验按响应类型分开处理是否可行。
- G13F：肌电 + 响应类型 + 幅值方向物理约束。目的：直接处理用户指出的趋势像但幅值/方向物理意义不对的问题。
- G13G：脑电教师 + 连续风格 + 响应类型辅助学习。目的：检验脑电教师蒸馏收益能否和响应类型监督结合，但推理时仍不使用生理输入。
- G13H：脑电教师 + 肌电学生 + 响应类型辅助学习。目的：重新评估脑电教师和肌电学生的组合，重点看困难样本和响应类型而不只看整体误差。
- G13I：脑电教师 + 肌电学生 + 困难响应加权 + 物理约束。目的：把脑电教师重点用于大幅、反向、多段等困难响应，同时用物理约束压制幅值不足和错侧。
