# AutoDL Chrome 服务器开关工作流记录（2026-05-11）

## 1. 记录目的

本记录说明 Codex 已验证可以通过用户本机 Google Chrome 操作 AutoDL 控制台实例列表，用于查看实例状态、点击开机按钮、读取平台反馈，并按用户指定规则在可见实例之间顺序尝试。

这是一条工作流/基础设施记录，不是模型实验结果，不写入 `experiment_registry.md`。

## 3. 本次实际操作记录

### 3.1 只读检查

Codex 先通过 Chrome 插件连接用户浏览器，定位 AutoDL 标签页，并读取页面文本。

只读读取确认：

- 页面标题：`AutoDL算力云 | 弹性、好用、省钱，GPU算力零售价格新标杆`
- 页面 URL：`https://www.autodl.com/console/instance/list`
- 页面包含两个已关机实例：
  - `西北B区 / D98机`
  - `西北B区 / 034机`
- 两个实例均显示 `开机` 按钮。

### 3.2 尝试启动首选实例 `034机`

用户确认后，Codex 点击 `034机` 所在行的 `开机` 按钮。

AutoDL 返回提示：

```text
该主机空闲GPU不足
实例GPU需求数量：1 卡
主机GPU空闲数量：0 卡
```

结果：

- `034机` 未启动成功。
- 状态仍为 `已关机`。
- Codex 按当时规则停下，没有自动点击 `D98机`，等待用户再次确认。

### 3.3 尝试启动备用实例 `D98机`

用户再次确认后，Codex 关闭/避开前一个提示，点击 `D98机` 所在行的 `开机` 按钮。

AutoDL 返回同样提示：

```text
该主机空闲GPU不足
实例GPU需求数量：1 卡
主机GPU空闲数量：0 卡
```

结果：

- `D98机` 未启动成功。
- 状态仍为 `已关机`。
- 当前页面两个实例均已尝试，均因当前主机空闲 GPU 为 `0` 而失败。

## 4. 后续自动尝试规则

从本记录之后，用户明确要求 Codex 在 AutoDL 页面“开服务器”“启动服务器”“按规则开机”时，默认执行以下规则。

### 4.1 实例选择顺序

1. 如果当前页面包含 `034机`，优先尝试 `034机`。
2. 如果 `034机` 因 `该主机空闲GPU不足`、`实例GPU需求数量：1 卡`、`主机GPU空闲数量：0 卡` 等无 GPU 提示失败，则继续尝试当前页面中的其它实例。
3. 当前页面已知备用实例是 `D98机`。
4. 如果页面未来出现更多实例，则在 `034机` 失败后，继续按当前页面可见实例顺序逐个尝试，直到：
   - 某个实例成功进入 `开机中` / `启动中` / `运行中`，或
   - 当前页面可见实例全部尝试完。

### 4.2 哪些失败可以自动继续

只有下列情况可以自动继续尝试下一个实例：

- AutoDL 明确提示当前实例没有空闲 GPU。
- 实例仍保持 `已关机`。
- 页面没有要求改变实例形态、计费方式或创建新资源。

典型提示包括：

```text
该主机空闲GPU不足
实例GPU需求数量：1 卡
主机GPU空闲数量：0 卡
```

### 4.3 哪些情况必须停下确认

以下情况不自动继续或不自动点击，需要用户确认：

- 页面建议 `克隆实例`。
- 页面建议 `无卡模式开机`。
- 页面要求变更计费方式，例如包年包月、续费、充值、扩容、换规格。
- 页面出现价格、余额不足、欠费、支付、订阅、授权等提示。
- 页面要求删除、释放、重装系统、清空数据盘或更换镜像。
- 页面提示验证码、登录失效、账号安全验证。
- 页面上的实例名称/顺序和记录不一致，导致无法确认正在点击哪个实例。

### 4.4 成功后的默认动作

如果某个实例成功启动：

1. 停止尝试其它实例。
2. 读取并汇报成功实例名称、实例 ID、页面状态。
3. 等待页面进入 `运行中` 或出现 SSH/Jupyter 等入口。
4. 不自动执行 SSH 登录、Jupyter 打开、文件上传、关机或重装，除非用户继续要求。

### 4.5 关机规则

后续如用户要求 Codex 关机服务器：

1. 先读取当前页面实例状态。
2. 只对明确运行中的目标实例点击 `关机`。
3. 如果页面有二次确认，说明影响后再确认执行。
4. 不自动释放实例、删除数据或清空数据盘。

## 5. 安全和费用边界

- AutoDL 实例为按量计费资源，点击开机可能产生费用。
- 用户已经要求记录“无 GPU 时继续尝试当前页面其它实例”的默认偏好；后续在用户明确要求“开服务器/按规则开机”时，可以按本规则执行同一页实例尝试链。
- 如果用户只是让 Codex “看看服务器状态”，只读检查即可，不点击开机。
- 不选择 `无卡模式开机`，除非用户明确要求。
- 不选择 `克隆实例`，除非用户明确要求。
- 不处理充值、支付、续费、包年包月或规格变更，除非用户明确要求并在关键步骤再次确认。

## 6. 对当前项目的意义

这条工作流让 Codex 后续可以通过 Chrome 协助完成服务器准备动作：

1. 打开或接管 AutoDL 控制台。
2. 读取当前实例状态。
3. 按用户偏好的实例优先级尝试开机。
4. 如果某个实例没有空闲 GPU，继续尝试当前页面剩余实例。
5. 成功启动后回报可用实例，供后续 SSH 训练、日志监控或文件同步使用。

本工作流只负责网页控制台层面的开关机协助；具体训练任务、SSH 登录和实验执行仍应按项目实验日志和服务器操作记录另行记录。
