# 实验登记模板

把下面这一行复制到 `reports/progress/experiment_registry.md`：

```md
| YYYY-MM-DD | 实验 / 分析名称 | 这里解释缩写和后缀 | 这里写“这个实验到底想验证什么” | 单变量 / matched pair / 集成验证 | 最重要的改动 | 一句话结果 | proceed / no-go / needs control / archive | 链接 |
```

填写提醒：

- 一行只写一个 run 或一个明确的对照组。
- `命名拆解` 负责解释英文缩写、版本号和后缀。
- `白话解释` 负责告诉未来的你“这次实验究竟是在问什么”。
- 不要把长分析贴进表里。
- 如果已有独立报告，只在最后一列放链接。
