# G13H/G13I 三种子复验总结

## 直接结论

- G13H 在 seed2026 上看起来有突破，但补完 seed2027/2028 后，三种子平均没有超过当前已接受的 E5A、E6、E10C。
- G13I 加入困难响应加权和物理约束后，也没有形成稳定增益，三种子整体弱于 G13H。
- 因此本轮不能把 G13H 或 G13I 升级为新的最终主线；它们更适合作为“脑电教师 + 肌电学生 + 响应类型监督”路线的诊断证据。
- 当前论文级主线仍应保留 E5A/E6/E10C：E5A 和 E6 代表脑电教师路线，E10C 代表允许肌电推理路线。

## 解释

- G13H 三种子 test RMSE 均值为 0.4503，比当前 E10C 的 0.4424 高 0.0079，比 E5A 的 0.4402 高 0.0101，比 E6 的 0.4439 高 0.0064。
- G13I 三种子 test RMSE 均值为 0.4546，也没有超过 E5A/E6/E10C。
- seed2026 的正向结果主要说明这条组合有潜力，但 seed2027 的回落说明它还不稳定，不能用单种子结果包装成突破。
- G13H 的问题仍然是幅值偏保守；G13I 试图缓解这个问题，但没有换来整体和困难样本上的稳定收益。

## 当前建议

1. 暂停继续扩展 G13H/G13I 的同类变体，不继续简单加权或继续堆响应类型模块。
2. 保留 G13H/G13I 的结果作为负面边界：脑电教师 + 肌电学生 + 响应类型监督不能自动带来稳定提升。
3. 如果继续突破，下一步应回到失败机制本身：为什么 seed2027 掉、为什么幅值不足仍高、为什么 G11 不能超过 E6。
4. 对老师汇报时应说：G13 主动突破路线已经验证过，单种子有亮点，但三种子没有超过现有主线，因此暂不替换 E5A/E6/E10C。
