# G14 seed2026 后续决策：多候选轨迹不能只靠自由选择

## 1. 当前结论

G14A-D 已经完成 seed2026 完整训练。结果说明，多候选轨迹这个方向有诊断价值，但当前实现还没有形成新主线。

本轮最好的版本是 G14C：

- 测试 RMSE：`0.4603`
- 尾段误差：`0.3757`
- 综合选择指标：`0.8520`
- G11 困难样本 RMSE：`0.7120`
- G11 困难样本尾段误差：`0.7599`

它略好于 E2 的整体 RMSE，但仍弱于 E5A、E6 和 E10C。因此，G14A-D 不建议直接补 seed2027/2028。

## 2. 本轮说明了什么

第一，肌电仍然有帮助。G14B 相比 G14A 明显变好，说明在“响应先判别 + 多候选轨迹”的结构里，肌电仍然提供有效信息。

第二，单纯增加候选数量没有用。G14D 使用八个候选轨迹，但整体误差、尾段误差和综合选择指标都变差，说明问题不是候选不够多，而是模型不知道该选哪个候选。

第三，物理约束有一定帮助，但没有解决根本问题。G14C 相比 G14B 降低了整体 RMSE，也降低了幅值不足率，但尾段和综合选择指标仍然不好。

第四，G14C 对 G11 困难样本尾段有改善迹象，但整体困难样本 RMSE 仍不如 E10C，所以不能把它升级成主线。

## 3. 下一步不应该继续做什么

- 不建议直接补 G14A/G14B/G14C/G14D 的 seed2027/2028。
- 不建议继续把候选数量从 8 个加到更多。
- 不建议继续只靠“当前哪个候选误差最小”作为候选选择监督。
- 不建议只因为整体 RMSE 比 E2 略低，就把 G14C 当作新主线。

## 4. 下一步应该怎么改

下一轮 G14 应该把候选选择变得更稳定：

1. 先让模型明确判断响应方向、幅值等级、响应形态和尾段趋势，再让这些判断影响轨迹预测。
2. 候选轨迹不要完全自由生成，可以使用训练集中同类型响应的平均原型或相似事件原型作为参考。
3. 候选选择监督不要只来自当前候选的临时误差，而应该来自固定的响应类型标签。
4. 肌电继续保留为推理输入，因为它在 G14B 相对 G14A 的对比中仍然有效。

## 5. 建议下一轮版本

- G14E：车辆数据 + 连续风格 + 肌电 + 稳定响应类型监督 + 四候选轨迹。
- G14F：车辆数据 + 连续风格 + 肌电 + 训练集响应原型 + 原型残差修正。
- G14G：脑电教师 + 肌电学生输入 + 响应原型或稳定候选选择，重点看 G11 困难样本。

下一轮仍然先跑 seed2026，但如果某个版本在整体 RMSE、G11 困难样本、幅值不足、错侧和尾段上同时有实际改善，再补 seed2027/2028。
