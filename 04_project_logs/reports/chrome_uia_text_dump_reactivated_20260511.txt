在正式审查前，请先明确我们的研究目标：

我们的最终目标不是单纯追求某个模型的 RMSE 最低，而是希望形成一条有研究价值、能向老师和论文汇报的主线：

“连续驾驶风格 + 生理数据”是否能为事件触发后的方向盘/轨迹响应预测提供额外有效信息，并且这种信息是普通车辆历史输入、普通事件输入或常规轨迹预测模型难以替代的。

这里的“生理数据”不要狭义理解为当前某一种人工语义生理状态。它可以包括：
1. 原始生理特征；
2. 基线校正后的变化；
3. 数据自动学习得到的低维表示；
4. 和任务相关的驾驶员状态；
5. 训练阶段的脑电教师信息；
6. 推理阶段可部署的肌电、心率、皮电等输入；
7. 用于响应类型判断、门控、幅值/方向判断或困难样本识别的辅助信息。

我们希望最终回答的是：

1. 连续驾驶风格是否确实提供了稳定的个体差异信息？
2. 生理数据是否确实提供了车辆数据之外的驾驶员内部状态信息？
3. 脑电、肌电、心率、皮电分别应该扮演什么角色？
4. 生理数据是适合直接作为推理输入，还是更适合做训练教师、辅助任务、响应类型判断、可靠性门控或困难样本识别？
5. “连续驾驶风格 + 生理数据”的模型路线，是否能区别于普通车辆历史模型，而不是只是在普通模型上堆了一些弱特征？
6. 如果当前证据还不能充分证明生理数据有效，请指出证据缺口，并告诉我们应该怎样设计最关键的补充实验来证明或否定它。

请注意：我们并不是要求你强行得出生理数据有效的结论。相反，我们需要你严格判断：
- 哪些证据已经支持连续驾驶风格有效；
- 哪些证据已经支持某类生理数据有效；
- 哪些证据还不够；
- 哪些说法需要降级；
- 如果要真正证明“连续驾驶风格 + 生理数据”区别于其他模型，还缺哪些关键对照、指标或实验。
我现在给你一个证据包，里面包含从 E0 到当前 E19/G14 阶段的模型尝试、源码、实验报告、预测图、运行记录和项目日志。

证据包名称：
gptpro_E0_to_now_20260511.zip

请你不要急着给我一个新模型方案。请先做一次“研究路线和证据链审查”。

我们的任务背景是：
我们正在做事件触发后的方向盘/轨迹响应预测模型。最初目标是让模型预测更准确，并证明连续驾驶风格和生理数据对预测有帮助。后来我们发现，模型很多时候只是趋势像，但方向、幅值、零线两侧、尾段回正/漂移等物理意义不一定对。比如真实轨迹是明显大幅打方向，模型却只预测成轻微变化；或者真实在 0 上方，预测在 0 下方，这种即使 RMSE 不算特别差，物理含义也不对。

请你先按这个顺序阅读材料：
1. 00_README_CN.md
2. 01_timeline_CN.csv
3. 02_reading_guide_CN.md
4. 01_overview_selected_figures/01_阶段进展总览_CN.md
5. 01_overview_selected_figures/selected_figures/ 里的关键表格和预测图
6. 03_reports/ 中的 E0-E19、G11/G12/G13/G14 分阶段报告
7. 必要时再看 05_source_code/ 里的源码

我现在最担心的问题是：
我们是不是有点像“无头苍蝇”一样，一直在加版本、改结构、改融合方式，但模型能力没有真正上去？
现在好像无论怎么改参数、加生理、加脑电教师、加响应类型、加物理约束、多候选轨迹，效果都比较接近，没有出现明确突破。
我也不确定我们是否真的证明了“生理数据有用”，还是只是证明了某些版本在某些指标上有一点变化。
另外，像粗细双头、连续风格、当前解码结构、当前损失函数、当前评价标准，这些也不应该被固定死。如果它们本身限制了模型能力，也应该允许被推翻或重构。

请你重点完成下面这些审查任务。

一、审查我们的证据链有没有逻辑漏洞

请你从 E0 到 E19、G11/G12/G13/G14 的结果出发，判断目前哪些结论是可靠的，哪些结论证据不足，哪些结论可能被我们说得太强了。

请重点审查：
1. “连续驾驶风格有效”这个结论是否充分？
2. “脑电有用”这个结论是否充分？它是推理期有用，还是训练期教师有用，还是只是在某些设置里有用？
3. “肌电是当前最强非脑电生理信号”这个结论是否充分？
4. “心率、皮电没用”这个说法是否过强？更准确应该怎么表述？
5. “四信号融合不行”是否能说明生理融合路线不行，还是只能说明当前融合方式不行？
6. E10C、E5A、E6、G13H/G13I、G14C/G14G 这些结果是否能支持我们现在的主线判断？
7. 目前是不是存在训练/验证/测试样本、被试分布、事件锚点、指标选择或图像挑选上的偏差？

请你明确列出：
- 可以保留的结论；
- 需要降级表述的结论；
- 目前不能下的结论；
- 可能存在逻辑跳跃的地方。

二、判断我们是不是方向跑偏了

请你判断：我们现在一直围绕“连续风格 + 生理/脑电 + 粗细双头 + 蒸馏/门控/响应类型”扩展，是不是已经陷入局部修补？

请你重点回答：
1. 当前模型能力卡住，可能是因为生理数据没用，还是因为模型结构没有能力用好？
2. 当前粗细双头结构是否可能限制了模型能力？
3. 当前输入方式是否可能过于静态，只把生理信号当成一个上下文向量，导致时序信息被浪费？
4. 当前任务是否本身存在不可预测成分，比如事件触发后驾驶员真实响应受未来道路/交互/个体策略影响，而这些信息没有输入？
5. 当前评价方式是否把模型带偏了，比如 RMSE 下降一点，但方向、幅值和物理意义没有改善？
6. 我们是不是应该暂时停止继续堆版本，先重新定义任务、输入、输出和评价？

请你不要默认我们必须继续沿用粗细双头，也不要默认现在的网络结构必须保留。如果你认为应该重构，请直接说明。

三、重新评估“生理数据到底有没有用”

请你把“生理数据有用”拆成几个层次判断：

1. 生理数据是否包含和驾驶响应相关的信息？
2. 生理数据是否在当前样本划分下带来可复现提升？
3. 生理数据是否改善了困难样本，而不是只改善普通样本？
4. 生理数据是否改善了方向、幅值、错侧、尾段等物理问题？
5. 生理数据是否适合作为推理期输入？
6. 生理数据是否更适合作为训练期教师、辅助标签、门控信号或响应类型判断信号？
7. 脑电、肌电、心率、皮电应该分别怎么定位？

请你结合现有证据，给出最严谨的判断。不要为了鼓励我们继续做生理数据而说它有用，也不要因为当前结果不强就直接否定它。

四、分析模型为什么整体提升不明显

请你从以下可能原因里判断最可能的瓶颈，并给出证据：

1. 输入信息不足；
2. 标签本身噪声大或任务不可预测；
3. 事件锚点不够准；
4. 样本划分或被试分布导致泛化困难；
5. 模型结构容量不够；
6. 模型结构不适合多模态/时序生理信号；
7. 损失函数和评价指标不匹配；
8. 输出轨迹被平均化，导致幅值不足；
9. 响应类型混在一起训练，导致模型学到平均响应；
10. 生理信号质量、时间同步或标准化方式有问题；
11. 当前实验矩阵虽然多，但没有真正打到关键瓶颈。

请你按可能性排序，并说明每一项应该如何验证。

五、判断下一阶段应该先改什么

请你不要直接给一堆新版本。请先判断下一阶段最应该优先做哪一类事情：

1. 重新定义评价标准；
2. 重新做数据和标签审计；
3. 重新检查事件锚点和预测窗口；
4. 重新设计输出形式，比如先预测响应类型/方向/幅值/延迟，再预测轨迹；
5. 重新设计模型结构；
6. 重新设计生理信号使用方式；
7. 做被试泛化或留一被试验证；
8. 暂时停止生理路线，先把纯车辆模型能力做上去；
9. 保留生理路线，但只把生理作为辅助任务或教师信息；
10. 直接转向更强的时序模型、多模态模型或生成式/多假设预测。

请你给出排序，并说明原因。

六、请你给出一个新的长期目标

我们希望接下来不是继续无目的地跑实验，而是形成一个新的长期目标。这个目标不应该预设“粗细双头必须保留”，也不应该预设“生理数据一定有用”或“一定没用”。

请你帮我们重新设定一个长期目标，包括：
1. 最终目标；
2. 阶段目标；
3. 每阶段要回答的核心问题；
4. 成功标准；
5. 停止规则；
6. 哪些路线应该暂停；
7. 哪些路线值得继续；
8. 需要补的关键审计；
9. 需要补的关键实验；
10. 最终如何形成能向老师汇报的主线。这个长期目标必须保留我们的研究主旨：
不是单纯做一个普通轨迹预测模型，而是要判断并尽可能建立“连续驾驶风格 + 生理数据”对事件后驾驶响应预测的额外价值。

但同时，这个目标不能强行预设生理数据一定有效。请你把长期目标设计成一个可证伪、可审查的目标：
- 如果连续驾驶风格确实有效，要说明如何作为稳定基础；
- 如果某类生理数据有效，要说明它通过什么方式有效；
- 如果某类生理数据当前无效，要说明是信号本身无效、表示方式不对、融合方式不对，还是评价方式没有捕捉它的作用；
- 如果当前模型结构用不好生理数据，要允许重构模型，而不是继续在旧结构上微调；
- 如果最终只有肌电或脑电教师有价值，也要形成清晰主线，而不是把所有生理信号都强行融合。 

七、请你特别关注预测图中的物理问题

请你不要只看表格。请结合预测图判断：
1. 模型是不是经常只预测趋势，但幅值不够？
2. 是否存在错侧问题？
3. 是否存在真实大幅响应被预测成轻微响应？
4. 是否存在尾段漂移或回正失败？
5. 是否存在反向修正、多段修正被压成平滑单峰？
6. 这些问题是否说明当前模型输出形式或损失函数有根本缺陷？请你特别判断：如果我们的目标是证明“连续驾驶风格 + 生理数据”区别于其他模型，那么最小但有说服力的证据链应该是什么？

请你设计这条证据链，包括：
1. 必须有哪些基础对照；
2. 必须有哪些消融实验；
3. 必须有哪些三种子或多种子复验；
4. 必须有哪些分被试结果；
5. 必须有哪些困难样本结果；
6. 必须有哪些物理指标；
7. 必须有哪些预测图；
8. 什么情况下可以说连续驾驶风格有效；
9. 什么情况下可以说生理数据有效；
10. 什么情况下只能说“当前方式未能利用好生理数据”；
11. 什么情况下应该承认“当前数据不足以证明生理数据有效”。


如果你认为当前 RMSE 不足以作为主要指标，请你建议一套更合理的评价体系。

八、请你最后给出明确建议

请你最后用清晰结论回答：

1. 我们目前是否已经充分证明连续驾驶风格有效？
2. 我们目前是否已经充分证明生理数据有效？
3. 我们目前是否已经充分证明脑电有效？
4. 当前最强主线应该保留哪些？
5. 哪些路线应该停止？
6. 当前最大瓶颈是什么？
7. 下一步最应该做的 3 件事是什么？
8. 如果你认为我们已经跑偏，请明确指出跑偏在哪里。

5. 模型整体提升不明显的最可能瓶颈排序
第 1 位：损失函数和评价指标不匹配
可能性最高。
证据是你描述的物理问题：趋势像、幅值不足、错侧、大响应被压小、尾段漂移。RMSE/MSE 类损失天然会奖励平均解，尤其在响应类型混合时。
验证方法：
在不改模型主体的情况下，加入并报告物理指标：错侧率、方向 F1、大响应召回、峰值幅值误差、峰值时间误差、尾段回正误差、零线穿越错误、signed area error。若 RMSE 接近但物理指标差异很大，说明原评价体系带偏了。
第 2 位：输出轨迹被平均化，响应类型混在一起训练
非常可能。
真实响应如果分为大幅左打、小幅左打、无明显响应、小幅右打、大幅右打、先反向再修正、尾段回正等类型，单一回归头会学到中间轨迹。
验证方法：
先对真实标签按峰值方向、峰值幅值、响应延迟、尾段斜率、零线穿越次数聚类。然后做“oracle 响应类型”实验：给模型真实响应类型，看轨迹误差是否明显下降。如果 oracle 类型显著改善，说明瓶颈在响应类型混合。
第 3 位：输入信息不足，任务存在不可预测成分
很可能。
如果模型缺少未来道路几何、交互对象变化、事件严重程度、驾驶员视线/感知时刻等信息，真实响应可能不可由当前输入唯一决定。
验证方法：
做上限实验：加入 oracle 信息，例如真实响应类型、真实峰值方向、事件后短窗口车辆状态、道路/交互强度标签。如果 oracle 信息显著降低错误，说明原输入不足。

事件触发时刻不一定等于驾驶员感知时刻，也不一定等于生理反应开始时刻。若锚点偏差 200–500 ms，生理和车辆响应会错位。

在正式审查前，请先明确我们的研究目标：

我们的最终目标不是单纯追求某个模型的 RMSE 最低，而是希望形成一条有研究价值、能向老师和论文汇报的主线：

这里的“生理数据”不要狭义理解为当前某一种人工语义生理状态。它可以包括：
1. 原始生理特征；
2. 基线校正后的变化；
3. 数据自动学习得到的低维表示；
4. 和任务相关的驾驶员状态；
5. 训练阶段的脑电教师信息；
6. 推理阶段可部署的肌电、心率、皮电等输入；
7. 用于响应类型判断、门控、幅值/方向判断或困难样本识别的辅助信息。
