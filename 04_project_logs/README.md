# 04_project_logs

这个目录放项目日志、状态说明和项目级参考文档。

当前分区说明：

- `references/`：当前状态锚点、恢复入口、关键参考说明。
- `reports/`：主进度日志、实验登记、日报、专题报告。
- `dataset_docs/`：数据目录和历史工作区拆分后的说明文档。

当前最重要入口：

- `references/current-state.md`：恢复项目时先读。
- `reports/progress/experiment_registry.md`：看实验登记表。
- `reports/project_progress_master.md`：看详细长期进度。

使用约定：

- 任何实质性整理、修复、实验推进，都先补这里的项目日志，再做简短总结。
- 历史说明尽量保留在这里，不要混回代码或结果目录。
